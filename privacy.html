Политика конфиденциальности

Приложение «Shamil YouTube» — личный инструмент владельца YouTube-канала Шамиля Габзалилова. Им пользуется только владелец, для своего канала.

Какие данные используются

Через YouTube Data API приложение получает данные канала владельца: список видео, их названия и описания, комментарии к видео и субтитры. Приложение публикует ответы на комментарии и меняет названия и описания видео только по решению владельца.

Хранение и передача

Ключ доступа хранится только на компьютере владельца. Данные не продаются, не передаются третьим лицам и не используются для рекламы. Использование данных, полученных из API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Отзыв доступа

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions.
